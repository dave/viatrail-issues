# Viatrail issues

Known issues and bug reports for the Viatrail app, on iPhone and Android.

There is no code here: this is only the public list of problems we know about, and their state.

**Found a bug?** Email dave@viatrail.app, or reply to any Viatrail email. We file it here, written so it holds no personal details, and close it when it is fixed.

Labels: `known-issue` is a problem we know about, often with a workaround; `iOS` and `Android` name the app it affects.
